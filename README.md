## Игровой процесс

Вы управляете космическим кораблём, что бороздит космическое пространство.
Навстречу вам летят вражеские корабли, которые в зависимости от выбранного
уровня для прохождения имеют разные вариации. 

Для борьбы с вражескими кораблями и их выстрелами игрок может выстреливать 
обычными и пробивающими снарядами. Если вражеский корабль сможет пройти 
в левую часть экрана - игрок получит штраф по очкам и урон по здоровью, 
аналогично, если вражеский корабль удариться с вами или его снаряд попадёт 
по вам. За уничтожение врага вы получаете очки. 

Цель игры - набрать **1000**
очков. В бесконечном режиме ваша цель просто набрать больше всего очков.

### Управление

```ЛКМ``` - обычный выстрел

```ПКМ``` - особый выстрел, который пробивает насквозь

```ESC``` - выход в меню или из игры

*Режим разработчика:*

```TAB``` - включает режим разработчика

```SPACE``` - позволяет досрочно закончить уровень

```Колесо мыши``` - +100 очков



## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/bulatziyatdinov/SpaceWarrior
```

2. Перейдите в папку проекта:
```bash
cd SpaceWarrior
```

3. Создайте виртуальную среду:
```bash
python -m venv venv
```

4. Активируйте виртуальную среду:

Для Windows:
```bash
./venv/Scripts/activate
```

Для Linux/macOS:
```bash
source venv/bin/activate
```

5. Установите зависимости:
```bash
pip install -r requirements.txt
```

6. Запустите приложение:
```bash
python main.py
```
